Summary:
  Implemented `record_git_commit(message, target_file)` in `serve.py` using Git
  plumbing (`read-tree`, `add -f`, `rm --cached`, `write-tree`, `commit-tree`,
  and `update-ref refs/heads/private_data`) with a dedicated `.git/private_data.index`
  file. This ensures:
  - All `data/*.json` changes (task updates, database creation, database deletion,
    board resets, and shutdown flushes) are committed directly to the `private_data`
    branch.
  - The `main` branch and working tree index are never touched or polluted by
    `data/*.json` commits.
  - Every commit message automatically includes `Agent: Antigravity` and
    `Model: Gemini 4 Argon (Medium)`.

Summary:
  Implemented the core zero-dependency Python 3 HTTP server (`serve.py`) using
  `ThreadingHTTPServer` and `SimpleHTTPRequestHandler`, providing full API parity
  with the original Ruby/Node backends:
  - Thread-safe datastore access via `threading.RLock()` and atomic file replacement
    (`.tmp.<pid>.<tid>` + `os.replace`).
  - Multi-database management (`sanitize_db_name`, `db_file_path`, `list_databases`,
    `read_board_data`, `write_board_data`, `DEFAULT_SEED`, `SAMPLE_SEED`).
  - Complete REST endpoints with CORS support:
    * `GET/POST/PUT /api/board`
    * `GET/POST/DELETE /api/databases` (protecting `default`/`board` from overwrite or deletion)
    * `GET /api/health`
    * `POST /api/reset`
    * `GET/POST /api/config` (`gitCommitBatchSize`, `pendingGitChanges`, `forceCommit`)
  - Automatic port discovery (`8080`..`8090`) and graceful `SIGINT`/`SIGTERM` shutdown.
